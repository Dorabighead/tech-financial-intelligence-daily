## 三、AI 与 Agent

### 3.1 【重点】Gemini 4 Carbon 全量开放：定价策略比能力更值得看

**时间线**：10-28 发布 → 两周内仅通过 **Fairwind 计划**向少数网络安全防御机构开放 → **11-10（美东）** 面向所有付费开发者与企业开放。

**能力定位**：与 Gemini 4 Argon 分工明确——Argon 承担绝大多数日常编码与知识工作，Carbon 面向"愿意花更多 token 换确定性"的长周期任务，核心机制是 **Extended Verification Loops（扩展验证循环）**：投入更多 Thinking Token，探索多条路径，执行—检查—修正直至收敛。

**自报基准（注意：均为 Google 自测）**：CursorBench 4.0、Perplexity WANDR、Zapier AutomationBench **三项第一**；单任务成本**不到表现次优外部模型的一半**；ARC Prize 榜单标注其评测成本为 7,200 美元。

**价格才是重点**

| 档位 | 输入 / 百万 token | 输出 / 百万 token |
|---|---|---|
| 推广期（至 11-30） | **$2** | **$10** |
| **12-01 起** | **$4** | **$20** |
| Claude Fable 5.2（对比） | $8 | $40 |

也就是说 Carbon 的真实价格是 Fable 5.2 的**一半**，且 12 月起翻倍——这是一次明确的"先用补贴换装机量、再用效果锁定留存"的操作。**对采购方的实际建议：把 11 月当作窗口期做压力测试，12 月再按真实价格重算单位任务成本。**

**/swarm（Antigravity 预览）**：一条提示词拉起一支可实时追踪的智能体团队——Carbon 负责架构设计、协调与审计，轻量模型并行实现，另有对抗性验证器逐次检查变更。这是"多 Agent"从演示走向产品形态的一步，但要注意它与 Harness 强绑定：**能力 = 模型 × 编排**，离开 Antigravity 就复现不了。

### 3.2 【重点】AlphaProof Code：把 Signal 的编译后机器码纳入证明范围

| 维度 | 数值 |
|---|---|
| 目标 | Signal 加密协议**编译后**的设备代码（非仅协议设计或源码） |
| 形式化规格 | 约 **2.6 万行** Lean 规格 + AArch64 指令集形式化语义，**逐条人工审核** |
| 产出 | 约 **650 万行**经机器检查的 Lean 证明 |
| 耗时 | **4 周**（Google 称相当于专家团队数年工作量） |
| 需人工复核 | 约 **1%** 代码库 |
| 负向验证 | 重新植入 2 个历史真实漏洞，系统均给出**机器检查通过的反例证明** |

**为什么这件事比模型发布重要**

1. **它闭合了一个长期缺口**：密码学可以证明"协议设计安全"，代码审计可以找"实现漏洞"，但"理论上安全"与"设备上真的安全"之间一直隔着实现、编译与优化。这次把 AArch64 机器码语义纳入验证，等于是对**实际运行的二进制**做证明。
2. **它改变了安全工程的成本结构**：形式化验证过去是"只有内核、飞控、智能卡才用得起"的手段，因为规格与证明都要专家写。当证明生成被 agent 化，瓶颈就从"证明"转移到"规格"——而规格恰恰是人类最该负责的部分。
3. **"反例证明"是关键设计**：只会给正确代码开证明的系统是无用的（甚至有害）。能对错误实现给出可机器检查的反例，才使它具备工程可信度。
4. **必须说清的边界**：它只证明"已被明确表达出来的属性"。规格写漏了，证明再漂亮也没用；1% 的人工复核也不是零风险。Google 表示将与自动化修复工具 **CodeMender** 结合，形成"发现—修复—证明"的闭环——那才是终局形态。

> 与昨日 Co-Design Bench（99% 基准 vs 26.4% 完整通过）放在一起看：**"完成"的定义正在被抬高**。过去"能跑"算完成，现在要求"通过验收"，下一步会要求"可被证明"。

### 5.1 Vite 8.1：三个方向性变化

（Vite 8 为 2026-03 发布，Rolldown 取代 esbuild + Rollup；以下为 8.1 线新增能力）

1. **实验性 Bundled Dev 模式**：开发期也走打包路径，解决"dev 与 build 行为不一致"这个老问题——代价是启动变慢、HMR 语义变化。这是对大型项目（尤其 monorepo）最实际的一条。
2. **Chunk Import Map**：构建产物用 import map 描述 chunk 依赖，减少运行时的预加载推导。
3. **WASM ESM 集成**：`init` 查询导入，默认导出为返回 Promise 的初始化函数，可传 `importObject`；由 vite-plugin-wasm 作者 Menci 的实现上游化。

另有两条值得留意的细节：

- **Lightning CSS 又近一步**：8.1 与 Lightning CSS 团队补齐了"在 CSS 中导入外部 CSS"与"插件通过 API 注册文件依赖"两项 PostCSS 有而 Lightning CSS 缺的能力，官方明确表示**考虑在下一个主版本把默认 CSS 处理器切到 Lightning CSS**。想提前对齐可设 `css.transformer: 'lightningcss'`。
- **`import.meta.glob` 新增 `caseSensitive`**：对 Windows/macOS 这类大小写不敏感文件系统尤其有用（同一文件两种写法），并已同步修复 HMR 的 glob 匹配器，保证 dev 与 build 行为一致。

### 5.2 TypeScript 7.1 Beta：新 API 的真正含义

上周已提示 7.1 RC 未按期、仍在 Beta。Beta 里最需要提前准备的不是语法，而是 **Compiler API 的彻底重组**：

| 入口 | 作用 |
|---|---|
| `typescript/sync` | 同步编译器客户端（options / checker / program） |
| `typescript/async` | 同一套能力的 Promise 版本 |
| `typescript/fs` | 请求作用域的文件系统（含分层/内存实现） |
| `typescript/ast`、`typescript/ast/is`、`typescript/ast/factory` | AST 节点类型、类型守卫、节点工厂 |

**三个实操要点**

1. **必须用 `using` 释放对象**：编译器跑在 Go 侧，`API`/`Program`/`Snapshot` 持有的内存 JS GC 无法回收，忘记 `using` 或手动 `dispose()` 会在长驻工具里稳定泄漏。
2. **API 不读 tsconfig**：需要自己 `parseCommandLine`，这与 `tsc` 的行为不同，迁移时要显式处理。
3. **Snapshot 是给编辑器/监听器用的**：`api.createSnapshot()` + `snapshot.update()` 增量推进，Program ID 跨更新保持不变，且旧快照仍可查询——这是把"每次编辑全量重算"改成"增量"的关键。

**仍然有效的迁移警告**（承接昨日）：`tsgo --noEmit` 抓不到的三类问题——被删除的 tsconfig 选项（`keyofStringsOnly`、`out`、`prepend`、`charset` 等，且 `ignoreDeprecations` 本身也被移除）、依赖 Compiler API 的工具链（`ts-morph`、`ts-patch`、`typedoc`、type-aware lint）、以及 `emitDecoratorMetadata` / `const enum` 的行为变更。**建议在 CI 里并行保留 TS 6 跑这些工具。**

### 6.1 云原生：CNCF 一年成绩单，以及 Agent 身份层的补位

**CNCF 年度数据（11-10 于 KubeCon NA 发布）**

- 项目总数 **231 个**（一年新增 32 个）；全球云原生开发者 **2,120 万**（一年 +550 万）；全年活动参会 **82,000 人**、覆盖 50+ 国家；
- 新晋白金会员 8 家：**Adyen、Broadcom、CoreWeave、CVS、HAProxy、NVIDIA、OVHcloud、Vultr**——芯片厂、neocloud 与企业用户同时入场，这个组合本身就说明云原生的买方结构变了；
- 新 Sandbox：**OpenShell**（NVIDIA 主导，agent 安全运行时）、**Agent Substrate**（在 Kubernetes 上执行不可信 agent 代码的零信任运行时）、gVisor、KubeRay、OpenRL；
- 晋级：**Kubeflow 毕业**；**HAMi 进入孵化**（异构加速器共享与调度）；**Kubernetes AI Conformance 达 40 个认证平台**。

**OpenShell 值得单独说**：它管的是"agent 能执行什么、能访问哪些资源与数据、推理请求被路由到哪里"，在 agent 外围做策略执行（文件、网络、凭据、模型端点）。这与昨天提到的"SPIFFE 无法区分 agent 实例身份"是同一问题的两个解：**SPIFFE 管工作负载身份，OpenShell 管运行时行为边界**。

**Linux Foundation 同日启动 Agent Name Service（ANS）**

用 DNS 基础设施为 agent 提供身份、验证与发现，规范共 **7 份文档**：域名锚定的命名、注册与版本、DNS 发布、公开日志审计、完整性监控、agent 间认证。已有 11 家参与（Cisco、Cloudflare、DigiCert、GoDaddy、Infoblox、Salesforce、OWASP 等），AGNTCY Agent Directory Service 支持验证 ANS 身份，ANS Finder 通过 ARD 注册表一致性测试。

**把这三件事连起来看**，agent 身份正在形成三层：

| 层 | 方案 | 回答的问题 |
|---|---|---|
| 命名与发现 | **ANS**（DNS + 公开日志） | "这个 agent 是谁、属于哪个域、是否被篡改" |
| 工作负载身份 | SPIFFE / 按实例签发（提案中） | "哪个实例在执行"（昨日指出的缺口） |
| 运行时边界 | **OpenShell** / Agent Substrate | "它能碰什么、能调哪个模型端点" |

**这是 2027 年最值得押注的基础设施方向之一**：身份不是权限配置问题，而是"实例可互换"这一假设在 agent 场景下失效后的重建。

> **Outlook 这条的方法论价值**：CVSS 6.5 排不进"连夜拉群"的名单，但"已确认在野利用"把它推到第一优先级。**分数是静态的，利用是动态的**——补丁优先级应看 EPSS/KEV 与暴露面，而不是只看 CVSS。

### 6.3 一个被低估的对照

昨日是「Co-Design Bench 说 agent 只能完整完成 26.4% 的真实任务」，今日是「一个 agent 辅助的研究者一次放出 33 个零日」与「一个 agent 团队四周产出 650 万行可机器检查的证明」。**同一批能力，在"完成任务"维度上还很弱，在"生成候选结果"维度上已经极强。** 这解释了为什么安全行业最先被冲击：安全工作的产出物（漏洞、证明、报告）恰好是**可自动验证**的，而"完成任务"往往需要不可验证的判断。

## 七、交叉观察

**1. 利率重新成为 AI 估值的分母，而且这次是"真加息"而非"降息推迟"**
10 月核心 CPI 连续三个月 0.3%，2 年期一度 +21bp，10 年期盘中 5.025%，12 月加息 25bp 概率 84.2%、50bp 从零升至 11.8%。同时洛根称"至少还需两次 25bp"，鲍曼则警告"美股估值存在大幅回调风险，应关注 AI 回报令人失望带来的金融稳定风险"——**这是美联储官员第一次把"AI 回报不及预期"明确列为金融稳定风险**。在这套组合下，英伟达在营收预期 +91% 的背景下两日跌 9%，说明市场当前定价的不是业绩，而是贴现率。

**2. "可验证"正在成为新的交付标准**
今天四件事指向同一处：AlphaProof Code 用机器检查的证明替代人工审计；Co-Design Bench 用隐藏验收标准替代"能跑就算过"；Cloudflare 的 security-audit-skill 强调"可独立复核的发现文件"；N-able 的恢复在线需要"证据"。**当产出者从人变成 agent，验收方式必须从"看结果"变成"查证明"**。这不是流程美化，是唯一可行的规模化前提。

**3. Agent 身份的三层结构今天补齐了两层**
昨天指出 SPIFFE 无法区分 agent 实例；今天 ANS 补上"命名与发现"（DNS + 公开日志审计），OpenShell 补上"运行时边界"（文件/网络/凭据/模型端点策略）。中间那层"按实例签发身份"仍是提案。**这意味着 2027 年 agent 上生产的主要摩擦点会集中在中间层**——也是创业与标准争夺最激烈的地方。

**4. 安全处置的动词变化，比漏洞数量更能说明问题**
"关机"成为官方建议，意味着防御方承认自己无法描述安全状态。与此同时，攻击侧的产能因 AI 提升了数量级（一人 33 个零日）。**当"找洞"边际成本趋零，"修复"的边际成本不变，唯一可扩展的解法是减少暴露面与缩短恢复路径**——而不是加快补丁节奏。对工程团队的实际含义：资产清单与"能不能一键下线"要优先于"打补丁有多快"。

**5. 算力自给的三条平行线**
Google 一年四款 TPU（8tx 走机密计算、8i Max 走百万上下文，均 2027 交付，已近 100 家客户）；阿里把平头哥分拆赴港上市；台积电同期在建约 20 座厂、资本支出上限 640 亿美元、10 月营收 +59.7%。**这三条线分别在"专用化""资本化""产能"上推进同一件事：把算力从稀缺资源变成可规划的基础设施。** 而英伟达同日跌 5.5%，恰好是这条叙事的另一面。

**6. 一个需要警惕的数据点**
聚合媒体转述"Vercel 称安全审查上线不到一周，agent 发现 57,897 个漏洞、6,029 个严重或高危、自动修复 14,665 个"（C 级，未见到官方原文）。如果数字成立，它说明"AI 找洞"已经从研究演示进入商业产品；但**"发现"与"可利用"之间的落差极大**，这类数字在引用时必须标注统计口径，否则会制造虚假的安全感。
