#### 🆕 第七波：榜单从"Skills 编排"转向"运行时与本地环境"

- **kiri 是这一波最值得读的项目**。它的做法不是"再包一层"，而是**绕过 containerd/runc**：VM 内 PID 1 是一个约 900KB 的 Rust agent，一次 `clone3` 系统调用带着 `CLONE_INTO_CGROUP` 直接进入新命名空间和 cgroup，容器进程就是 agent 的直接子进程；宿主机与 VM 之间用 **vsock 单连接**通信。官方 bench：CLI 启动 **14.2ms**（Docker Desktop 243ms、OrbStack 442ms）、容器启停约 2.5ms、守护进程约 15MB、VM 空闲 60 秒休眠/0.15 秒唤醒；另有 `*.kiri.local` 本地域名 + 自带 CA 的 HTTPS、一条命令起单节点 k3s。
- **但它必须带风险提示**：项目 **2026-11-02 才创建**（两周）、最新 v0.2.1、**约 88% 的提交集中在单一维护者**、10 天内 +955% 属于病毒式增长。容器运行时是**特权组件**，直接操作 clone3/cgroup 意味着攻击面与 Docker 完全不同——**生产环境不要用，学习与本地开发可以试**。
- **DeepSeek 官方 chat-demo 的意义不在代码**：它是"全家桶 API（联网搜索/读链接/深度思考/语音/附件）"的**参考实现**，等于官方给出了"如何 1:1 复刻 App"的答案。同时官方明确写了两条边界：**仅供演示**；对外提供服务者**须自行承担内容安全审核、大模型登记、AI 标识等义务**——省掉的是搭壳时间，省不掉的是运营责任。
- **`dsh-our-free-model` 是一个需要警惕的信号**：它把"免登录、免 Key 调用前沿模型"做成插件，靠直连 **OpenCode Zen 网关**与 **Kilo AI 公共网关**实现。这类项目**没有任何服务条款与配额保障**，本质是把别人的试用额度/公共网关当免费 CDN；企业环境应视为**数据外泄风险**（提示词与代码会经过未知第三方），而不是"省钱工具"。其 75.7k star 与项目体量明显不匹配，**star 数不建议引用**。
- 一句话总结第七波：**当 agent 变成"常驻进程 + 高频短任务"，本地运行时（容器/VM/沙箱）重新成为瓶颈与创新点**。这与 11-13 观察到的 Claude-Cage（agent VM 隔离）是同一条线的两端——**隔离粒度正在从"进程"细化到"每次任务"**。

## 5. 计算机前沿：安全 / 基础设施

### 5.1 【主线】"脆弱星期五"之一：Check Point 网关被打穿后，ESXi 上跑的是擦除器，不是勒索软件

**事件链（Check Point 官方研究 + BleepingComputer 整理 + 全球威胁情报日报 11-14 复盘）**：

1. **进门**：通过网关公网暴露的 Mobile Access 门户利用 **PHP2Shell**（CVE-2026-109618 / 9.8 与 CVE-2026-109619 / 8.1，两个未认证 RCE）。PHP2Shell 的量化指标是近期最极端的一组：**EPSS 99.999%**（30 天内被利用概率接近 1）、10-26 已入 KEV、GitHub 上 PoC 仓库生态已形成（星数 1966/1083/1003…）、Nuclei 官方模板齐备。Amazon TI 观测到**利用早于 10-21 紧急补丁 4 天开始**——"补丁窗口"概念对它不适用。
2. **提权**：利用刚披露的 **CVE-2026-123039（DynamicCLI 提权，7.8，11-13 入 KEV）** 从"有访问"变 root。
3. **驻留**：PHP webshell + **TSGA 后门**（内嵌 TSProxy 网络组件，设计目标"看起来像业务流量"）。
4. **找目标**：用开源侦察工具 gogo 内网扫 VMware ESXi 主机。
5. **破坏**：在 ESXi 上部署 **destroy_v6 擦除器**——递归删除+零填充防恢复，另有快速模式。
6. **留话**：留下 DREAM_ANNEXATION.txt，提及"Dream Security Ltd."，内容为政治留言，**明确拒绝赎金谈判**。

**为什么"拒绝赎金"是最重要的情报**：所有按"勒索软件"写的应急预案对这类行动都不成立——没有"付钱换解密"的退路，只有"**有没有离线备份**"和"**多久能重建**"。归因上 Check Point 仅初步关联 PhiliKit 框架（ESET 曾关联 UNC5221 集群），**明确表示无法确信归因**，政治留言+疑似冒名署名的组合既可能是真旗也可能是假旗。

**处置**：所有 Management Server 与 Security Gateway 安装 **11 月 Jumbo Hotfix**（同时修 PHP2Shell 与 DynamicCLI）；已暴露网关按"完全失陷"排查（session 文件 `upload_progress_pwn`、异常 `CPconfigdaemon` 进程、防火墙日志空档、网关到 ESXi 的未授权 SSH）。

**同日 KEV 更新**：CISA 11-13 另将 **UnrealIRCd CVE-2026-114713**（分隔符处理）与上述 Check Point CVE-2026-123039 纳入 KEV。

### 5.2 【主线】"脆弱星期五"之二：N-able 最新补丁版照被打穿——洞在 EOL 的第三方组件里

- 研究员 Sean Bales 11-12 公开 N-central 两个零日利用（4EverAble2Shell / Agent2Shell），测试对象是 **11-10 刚发布的最新补丁版 2026.4.1.26 HF2**。
- **技术结论（本期最值得记录的一条）**：攻击链 = **Apache Axis 1.x 的 CVE-2026-90436（CVSS 9.8，未认证远程类实例化）** + N-central 本地提权。Axis 1.x **已 EOL 且官方明确不修复**——N-able 的补丁只修自家代码，**打包进去的第三方组件的洞还在**。SOAP fault 的 exceptionName 在引擎解析目标服务时即被解析，早于任何 per-service 认证处理器——"配置了认证"挡不住它。
- 实际后果：蜜罐观测到攻击 08:30 开始，**当天 12:50 已有 21 台 N-central 生产服务器在挖矿（XMRig，刻意只用约一半 CPU 核心规避监控），其中 19 台跑的是最新版 HF2**，分布美/加/英/法/德/瑞典/南非。
- **通用教训**：RMM/MSP 平台一台失陷等于成百上千端点失陷；对"EOL 无修复"的 9.8 分洞，处置只有两条——**关入口 + 假设已经进来过**。企业侧应把"依赖清单中的 EOL 组件"当作与"未修复 CVE"同级的暴露面管理。

### 5.5 llama.cpp / ggml 1.0.0：本地推理基础设施的"承担责任"时刻

11-13 发布（ggerganov 在 X 宣布，Hugging Face 官方博文）：

- **核心不是新功能，是版本化承诺**：`libllama` 与 `libggml` 今后**API/ABI 不兼容变更一律通过主版本号标示**（MAJOR=破坏性变更 / MINOR=向后兼容新增 / PATCH=bug 修复）——项目发展 3.5 年、大量下游依赖后的"成年礼"。
- **1.0 本身就是一次破坏性变更**：删除 35 个已弃用函数、移除 `llama_set_warmup` 与 `defrag_thold`，NextN 推测解码接口并入 llama.h——**升级即需适配，不要把 1.0 当作平滑更新**。
- 同版本技术增量：**FP8 KV 缓存**、主机内存上的 MoE 缓存、新模型架构、**llama-server 加固 SSRF/CORS/DNS 重绑定防护**（暴露到本机以外时关键）、OpenAI 兼容的 `/v1/audio/speech` 接口；已支持 **150+ 模型架构变体**与主流推测解码；分发覆盖 Debian/Homebrew/conda-forge/Winget/Docker/XCFramework。

## 6. 交叉观察

**观察一：本周是 AI 交易的总压力测试周——供给端与资本端 48 小时内同时定价**

英伟达财报（11-17，供给端权威公投）与 Anthropic 定价+上市（11-18/19，资本端压力测试）背靠背落地。三个可预先写下的判断框架：
- 被动指数需求 28% + 散户预期净买入 2.5 亿，意味着 ANT **首日很难大跌**；真实信号是**首日涨幅结构**（机构抢筹 vs 散户接盘）与**解禁后的第二个月**。
- 英伟达若给出保守 Q4 指引，"利空出尽"逻辑未必成立（FY28 EPS 预期 4.77→15.91 美元的下调空间太大）。
- 两件事都指向同一个终局问题：**AI 的单位经济模型能否在利率 5% 的世界里自洽**。Alphabet 发亚币债券融资 AI、英伟达 1,450 亿供应承诺、Anthropic 9,009 亿算力承诺——三条链的久期都在拉长，而 10Y 美债站在 5.13%。

**观察二："补丁范式"的失效周——三个假设被逐一击穿**

- PHP2Shell：利用早于补丁 4 天 → **"及时打补丁"失效**；
- N-able：最新补丁版照被打穿，洞在 EOL 第三方组件 → **"厂商会修"失效**；
- FAA：疑软件更新致瘫全国空管 → **"更新即安全"失效**。
三件事叠加的结论已经不能更直白：**边界设备与老基础设施要按"注定被打穿"来设计**——日志外发、ESXi 离线备份、管理面隔离、EOL 组件清单化管理，这四件事的优先级高于一切"及时打补丁"的 KPI。

**观察三：Skills 生态进入"金钱域"，治理真空同步暴露**

claude-trading-skills（+707/日）与 sure 同榜，说明 agent 能力扩张已越过工程域进入投资理财域。同一周，OpenAI 发布 35 秒阻断异常 agent 的"控制室"、IBM 收购 agent 凭据治理公司、Anthropic 上线"史上最严"封号机制——**供给侧在快速产品化治理能力，但消费侧的"金融建议类 agent"仍处于零监管状态**。这是 2027 年最可能出现新监管框架的领域。

**观察四：全球防御轮动的同构性**

11-13 同一天：美股买可口可乐/礼来/宝洁（历史新高），A 股买银行/保险/影视院线，而黄金同周大跌 4.6%——**这不是经典避险（黄金该涨），这是"高估值成长 → 现金与低波动"的迁移**。黄金被当作流动性来源抛售，说明部分持仓者已在为更大的波动准备弹药。若本周英伟达/Anthropic 双不及预期，防御板块是唯一有持续买盘的结构。

**观察五：中国算力的"地方基建加速"与"终端涨价"并存**

重庆词元产业行动计划（2028 年可调度智算超 10 万 P、算力券/词元券/语料券）、浙江 25.2 亿大模型训练平台采购、中卫 35 亿智算中心 EPC 落定——地方公共算力底座在提速；同期大疆因存储成本宣布消费终端涨价。**算力基建扩张的账单，正在通过存储/半导体价格向消费端传导**——这与 10 月 CPI 中"数据存储设备 +45.4%"形成完整闭环，是"AI 通胀"叙事最实的一条证据链。

**观察六 🆕：NAND 降价——"AI 通胀链"出现第一道反向裂缝**

过去三周本报告一直在记一条链条：AI 数据中心 → 存储需求 → 存储涨价（10 月 CPI 中"数据存储设备 +45.4%"）→ 消费终端调价（大疆 11-18 起涨价）。**11-16 今天，这条链的中间环节第一次断开**：

- 美银：**NAND 现货价自 10 月以来跌近 20%**，点名 NAND 是本轮上行周期**第一个应下调预期的品类**，原因是**手机厂与中国云厂商订单持续放缓**，定价权已从卖方转向买方。
- 但同一份报告**维持 DRAM 看涨**（Q4 +8%、明年 Q1 +5%），并强调美国 AI 数据中心相关芯片订单未减。
- 市场反应是精准的：**韩股 SK海力士/三星电子杀跌、港股"两倍做多海力士"跌 9%、A 股光模块/覆铜板跌停**，而 DRAM 侧的定价并未同步崩。

**这意味着"AI 硬件"不能再作为一个整体来交易。** 消费电子需求（NAND/手机/PC）与 AI 资本开支（DRAM/HBM/光模块）正在**脱钩**：前者在降温，后者被英伟达的订单簿托着。而 11-17 英伟达的指引，恰好会成为"后者还能撑多久"的第一次公开检验——**如果指引保守，NAND 的裂缝会迅速传染到 DRAM。**

**观察七 🆕：同一天，三个市场用三种方式给"AI 硬件"定价**

**同一个主题（AI 硬件），三个市场给出了三种归因。** 这说明当前不是"全球风险偏好同步收缩"，而是**各地在用自己的暴露面重新定价**：A 股怕失去订单、港股怕估值与信用同时收缩、韩股怕价格周期反转。对配置的含义很直接：**"AI 硬件"作为一个篮子已经失效，必须按"暴露在哪一条链上"拆开看。**

**观察八 🆕：AI 的久期问题被官方点破了**

把今天四条信息放在一张时间轴上：美联储说表外或有负债约 **3 万亿**、云厂商数据中心债务 **6,800 亿**（占 IG 发行 1/3）；Anthropic 的算力承诺 **9,009 亿**；英伟达的供应承诺与预付款 **1,450 亿**；Qwen4-Max 把单任务成本打下 **58%**、DeepSeek 缓存命中 **$0.003/M**。

**前三项是"久期在拉长"，后两项是"单价在坍塌"。** 两者并不矛盾——正因为单价快速下降，才需要更大的量、更长的合同来支撑收入；也正因为合同更长，才需要更多债务来垫资。**这是一个自我强化的循环，而美联储已经把它写进了《金融稳定报告》。** 真正的风险不是"AI 泡沫破裂"这种笼统判断，而是**当单价下降速度快于用量增长速度时，长周期合同的现值会被重估**——这会在财报的"收入确认"和债市的"再融资"两个地方同时显现。
