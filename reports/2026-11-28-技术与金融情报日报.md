### 1.1.1 【本期最重】浙大发布「确定性亚指数时间离散对数算法」——AI 产出的数学构造首次被人类密码学家当作前提往上叠结果

**事件**：浙江大学区块链与数据安全全国重点实验室（刘舒畅、张秉晟、任奎）向 IACR ePrint 提交论文 **2026/3020《A Deterministic Subexponential-Time Algorithm for the Discrete Logarithm Problem》**（校方官网 11-23 发布、ePrint 11-24 收到、11-27 批准；11-27 登上 Hacker News 首页 195/196 分）。宣称存在**一致确定性多带图灵机**，在素数域 $\mathbb{F}_p^*$ 与 $\mathbb{F}_p$ 上素数阶椭圆曲线上，最坏情况以 $2^{O(b/\sqrt{\log\log b})}=p^{o(1)}$ 时间、$2^{O(b/(\log b)^{1/4})}$ 空间求解离散对数，**零随机比特**，且不依赖广义黎曼猜想与光滑性启发式。技术上用「确定性条件期望构造小仿射区间因子基」+「保端部分收缩（terminal-preserving partial contraction）」绕过查表度数墙，再以 HNF 格陪集更新每获得一个反例至少压缩一半候选解空间；把维持 55 年的 $p^{1/2}$ 推进到 $p^{o(1)}$，补齐「后 ETH 时代确定性分解 vs 确定性离散对数」的最后一块拼图。

**关键限定（必须一起读）**：结论**条件于 OpenAI 2026 年 10 月的 Cauchy–Hermite 布尔张量收缩构造**——即此前挑战指数时间假设（ETH）的那个构造，**本身未经同行评审、正在外部复核**。论文为预印本、由人类撰写、非同行评审；结果是纯渐近的，**对 NIST P-256/P-521/Ed25519 等现役曲线无实际影响**，且未给出真实参数规模下的具体成本估计（10 月随机化版本称节省仅在规模 ≥ $2^{2^{17}}$ 的网络出现）。同日《泰晤士报》标题「AI 即将让网络安全失效，数学家忧心」明显超出摘要支持范围；Ledger CTO Charles Guillemet 定性为「**一道非常小的裂缝**」，当前算力不足以威胁钱包。

**发生日期**：2026-11-23（校方）/11-24（ePrint 收到）/11-27（批准 + HN 热议 + 泰晤士报）

**为什么值得关注**：这是本仓库 11-23 期「MiniMax 攻破多个 NIST 候选密码算法」、11-27 期「Aaronson『我的天啊 ×4』」这条主线的**决定性升级**——几周前的问题是"AI 的证明对不对"，现在**人类密码学家已开始在 AI 产出的构造之上垒结果，且垒向了保护互联网的椭圆曲线栈**。风险因此变成系统性的：若 OpenAI 构造被证伪，2026 年一整串密码分析工作会同时继承错误。可执行的动作不是改生产密码栈，而是把该构造当作**关键基础设施去做多 checker 独立审计**，并盯三个信号：具体成本估计是否出现、后量子迁移讨论是否提前十年启动、12/6–12/12 NeurIPS 是否有正式学术回应。

### 1.1.4 Anthropic 两篇研究：「AI 假遗忘」——低分不等于安全

**事件**：11-25 Anthropic 发布两篇研究（11-27 中文报道）。用「直接比较模型给每个答案原文的概率」替代选 ABCD 的常规阅卷法后：**23 个遗忘模型中有 14 个**，在遗忘前本来答对的多数题上仍把正确答案排在第一；单个被测模型约 **46 万个神经元，只把几十个调回遗忘前状态**，部分被压下去的正确答案就重新排到第一。题库为 WMDP-cyber（1987 道网安选择题）。结论：多数遗忘（unlearning）方法**只是把危险知识藏起来，并没有删掉**；拆开看有两种"藏法"（网安文本触发内部计算扰乱，或像埋了一道暗号开关）。对照 2024-10 Deeb & Roger 论文（Roger 署名单位即 Anthropic）从外部证明"删掉的知识微调后能恢复到 88%"。

**发生日期**：2026-11-25（发布）/11-27（中文报道）

**为什么值得关注**：直接冲击「用 unlearning 删除危险能力」这条安全路线的验收标准——**危险题考分降到盲猜水平 ≠ 知识已移除**。对做模型裁剪/合规下线的团队：验收应改用概率排序、神经元级恢复测试，而非仅看准确率。

### 1.2.1 【本期唯一窗口内可核验的官方正式版】Vite 8.4：dev server 安全模型从黑名单转向白名单

**事件**：Vite 官方发布 **8.4**（Releasebot 解析源日期 11-25；另有 `Vite 8.4.0 (2026-11-26)` 的完整 changelog，两日期并列不合并）。核心变化：
- **`server.fs.strict: 'extended'` + `server.fs.allow: []` → allow-list 文件服务检查**。原 `server.fs` 自 Vite 2.7 起是「黑名单」思路（列出敏感文件），需不断修补文件系统怪癖与 HTTP 解析绕过；官方称**因攻击增多**，8.4 引入更严格的白名单：只放行从入口可达的文件（含传递引用），并把插件加载的模块、CSS `url()` 引用也注册进允许列表。插件若生成非 import 引用的资产，可调用 `this.environment.addSafeModule`。**官方明确表示将在下一个主版本把白名单切换为默认**。
- **动态导入失败重试**：HTML 规范今年 7 月更新允许浏览器重试失败的模块 fetch（Chrome 156+/Firefox 155+/Safari TP 252）；8.4 改进 preload helper，使动态 chunk 的 CSS 在 import 重新执行时被重新获取。
- **CSS `url()` 支持 subpath imports**（解析失败回退为原始 hash URL）；官方推荐用 subpath imports 取代 `resolve.alias` / tsconfig paths，因 Node.js 与 TypeScript 原生支持。
- **重复 CLI 进程检测**：同项目已有相似选项的 dev server 在跑时报错退出，`--bypass-lock` 可绕过。
- **Wasm source phase imports**：`import source mod from './mod.wasm'` 直接得到 `WebAssembly.Module`；**TypeScript 7.1 将提供原生支持**，可取代 Vite 特有的 `.wasm?init`（此为路线图表述，非已发布）。
- **实验性 bundled SSR dev mode**；另有 40+ 项修复：hook 错误带插件名（#24107/#24151）、manifest 含 worker chunks、失败 CSS preload 重试、空 CSS 不产出、`cssCodeSplit:false` 时内联公共 chunk 的 CSS 去重、启动失败关闭 server、safeModulePaths 按环境隔离、`--configLoader=runner` 弃用、Windows 盘符大小写保持等。

**发生日期**：2026-11-25 / 11-26（官方发布）；11-27（媒体解读）

**为什么值得关注**：**dev server 安全模型的范式转换（默认拒绝）**，且官方已预告下个 major 默认开启。有自定义插件、或非 import 方式引用资产的项目，现在就应使用 `strict: 'extended'` + `allow: []` 做一次演练，别等 Vite 9 被动踩坑。Wasm source phase import 与 TS 7.1 的收敛也意味着前端构建链正在把 WebAssembly 当一等公民。

### 1.3.1 PostgreSQL 19（背景补记）：REPACK CONCURRENTLY 与「AI 挖 bug 拖长发布周期」

**事件**：PostgreSQL 全球开发组 **11-19 正式发布 PG 19**（官网新闻页可核验；距今 9 天、超 7 天窗口，按纪律标为背景补记，但本期出现大量中文技术深挖，值得系统收录）：
- **`REPACK [CONCURRENTLY]`**：原生在线表重组，取代需持 ACCESS EXCLUSIVE 锁的 `VACUUM FULL`/`CLUSTER`/外部 `pg_repack`；借逻辑解码捕获并回放变更、仅最后交换文件时短暂持锁。限制：需 MAINTAIN 权限；不支持分区表/UNLOGGED 表/物化视图/无主键或副本标识的表/系统表/非 heap 表，不能在事务块内；需约「表+全部索引」的空闲磁盘；并发更新删除超约 1.04 亿行会失败；**非 MVCC 安全**（持更早快照的并发事务可能看到空表）；推进 relfrozenxid 但不能替代 VACUUM 防事务 ID 回卷。进度查 `pg_stat_progress_repack`。
- **`pg_plan_advice` / `pg_stash_advice`**：把当前计划「翻译」成建议字符串（`JOIN_ORDER`/`HASH_JOIN`/`SEQ_SCAN`/`NO_GATHER` 等），只收窄规划器可选空间、不强制语义非法计划；后者按 query ID 存共享内存自动套用，**无需改业务 SQL 即可止血变慢的查询**。GEQO 开启时 join order 建议仅概率生效。
- **`WAIT FOR LSN`**：备库「读己之写」一致性原语，取代应用层轮询/硬编码 sleep；必须顶层命令、事务首条语句、执行时不持快照或锁；模式 standby_replay/standby_flush/standby_write/primary_flush。
- 其他：`ON CONFLICT DO SELECT`（一条语句 get-or-create，省一次网络往返、避免 no-op update 产生死元组）、`COPY ... FORMAT json`、jsonpath 字符串方法、`FOR ALL SEQUENCES` 逻辑复制同步序列、`CREATE PUBLICATION ... EXCEPT`、`CREATE SUBSCRIPTION ... SERVER`、并行索引 vacuum、autovacuum 评分、异步 I/O worker 动态扩缩容、聚合下推到 join 前、锁统计/恢复状态/REPACK 进度视图、`EXPLAIN ANALYZE (IO)/(WAL)`。
- **升级前必查的默认变更**：**JIT 默认关闭**、TOAST 默认压缩切 LZ4（存量不自动重压）、**移除 RADIUS 认证**、`pg_upgrade` 遇受影响 BRIN/GiST(inet/cidr) 索引直接拒升、库名/角色名/表空间名不允许换行符、MD5 登录告警、密码过期预警。
- **发布周期偏长的归因（媒体解读，非官方声明）**：中文公众号称「LLM 在开发与测试阶段挖出更多隐藏边界 Bug，大幅增加修复与代码审查工作量」，团队主动推迟属性图查询、新分区命令、时态更新与删除等激进特性。官网 Planet 11-24 亦有《PGAIBench and AAA: can AI safely change production Postgres?》条目呼应。

**发生日期**：2026-11-19（官方发布）/11-22~11-24（社区深挖）

**为什么值得关注**：承接 11-27 期「AI 找漏洞速度超过人类修补速度」主线——**PG 19 是这条主线里第一个把"AI 挖 bug"变成发布节奏变量的主流数据库版本**。能力上 `pg_plan_advice` 与 `WAIT FOR LSN` 直接解决生产痛点；但务必把"延期归因 LLM"当媒体解读，官方公告只说"简化大规模工作负载管理"。

## 2.1 【本期主线】国常会盘中定调「国家队」稳市，A股/港股午后暴力拉升

**事件**：**11-27 国务院总理李强主持召开国务院常务会议**，研究持续深化资本市场投融资综合改革。会议指出「资本市场事关经济发展大局」，要「坚持逆周期调节和改革攻坚两手抓，持续完善资本市场稳市机制，实施好存量政策、**谋划出台增量政策**」；**首次在国常会通稿中明确提及「国家队」**——「加力发挥『国家队』稳市作用，进一步优化**中央汇金公司的类『平准基金』功能，提供充足流动性保障**」；并要求推动上市公司加大分红回购力度、完善保险/企业年金/社保基金等中长期资金入市支持引导政策、加强输入性风险防范应对、依法强化全链条监管（严查财务造假、违规减持）。

据财联社梳理，本次有**三个「首次」**：发布时间首次前置至交易时段；「资本市场事关经济发展大局」首次写入通稿；「国家队」首次明确提及；稳市相关表述达 **285 字**亦为史上最多。叠加 11-06 国常会已提「完善资本市场稳市机制」，这是**国常会史上首次一个月内两次密集提及资本市场改革**。证监会党委书记、主席吴清当日主持党委（扩大）会议传达学习，强调「会同有关方面**抓紧研究出台相关增量政策**」；监管部门另表态重点推进两方面：优化股份回购规则（抓紧修订《上市公司股份回购规则》、提高回购增持再贷款覆盖率）、持续丰富投资产品工具（浮动费率基金、股债恒定比例等多资产指数基金、更多新指数股票 ETF），并严防「伪科技」借机上市、无真实业绩公司「注水」上市。

配套数据：10 月初以来上市公司回购增持实施金额近 600 亿元；股票型 ETF 净申购近 8000 亿元、总规模达 2.9 万亿元；沪深300/上证50 等宽基 ETF 净申购约 4000 亿元。

**发生日期**：2026-11-27（交易时段发布，午后生效）

**为什么值得关注**：这是「政策底」的**官方明示**，且是唯一一次把中央汇金的"类平准基金"定位写进国常会通稿——意味着后续稳市从相机抉择走向制度化、可预期的流动性供给。但按浙商证券梳理 2008 年以来七轮稳市周期，**政策底到市场底中位需 58 个交易日（2~3 个月）震荡整固**，需盯汇金增持、宽基 ETF 放量、社保险资加仓三个信号，不宜把单日长阳当反转确认。
