### 1.1 AI 与 Agent

#### 1. 智谱发布 GLM-5.4：Loop Transformer 架构首次用于旗舰模型
- **事件**：智谱（Z.ai）于 11-23 发布 GLM-5.4，首次将 Loop Transformer（循环 Transformer）架构用于旗舰模型：28 层循环执行两次共享权重计算，配合 Gated Progressive Updates、Hybrid KV Cache、Sparse Attention Index Reuse 控制循环开销。基于约 750B 参数的 GLM-5 基础模型；官方口径 30B 对照实验中 Loop 版本仅增加约 10% 训练计算量即获推理与长上下文提升。API 处于 Coming Soon，权重计划安全加固后开源。
- **发生日期**：2026-11-23。
- **为什么值得关注**：这是对「参数规模 / MoE 激活参数」之外第三条 Scaling 路线（**计算深度**）的规模化验证，与近期英伟达「超长上下文是死路」论文、MemT 等记忆压缩路线共同构成 2026 年底推理架构路线收敛的又一证据。若 750B 级循环架构的吞吐数据（官方称非高峰约 200 token/s）可复现，「同参数更多有效深度」可能成为下一轮模型竞争维度。注意：Loop/权重共享思路并非首创，其增量在于大规模落地与缓存工程。
- **来源**：AI 每日资讯 11-24 汇总（含官方博客转述）http://mp.weixin.qq.com/s?__biz=Mzg2NjA2MDAyOA==&mid=2247487326&idx=1&sn=ff749d6366094527f3a091c649f7b900 ；凤凰网 AI 早班车 https://i.ifeng.com/c/8yHbSyByo2X

#### 2. Anthropic 发布 Claude Ship：Agent 接管代码审查、修复与审批闭环
- **事件**：11-23，Anthropic 面向 Claude Team/Enterprise 的 GitHub 用户开放 Claude Ship Beta：Code Review（深度审查 PR）、PR Steward（处理 CI 失败、合并冲突、自动改码）、Claude Approvals（按团队策略审批，必要时交人工）。开发者可在 Claude Code 中用 `/ship` 启动全流程。
- **发生日期**：2026-11-23。
- **为什么值得关注**：Coding Agent 从「写代码」延伸到「**交付闭环**」——审查、修复、质量门禁、审批全部 Agent 化，且 Anthropic 的设计保留人工治理（审批策略由团队定义）。这与本仓库连续跟踪的 Code Mode / Agent Harness 主线吻合：企业引入 Coding Agent 的竞争点正在从代码生成效率转向**审查流程与责任边界的重新设计**。发布时点恰逢其 IPO 后首周，商业化路径（订阅 + 工作流深度绑定）值得对照 ANT 股价表现观察。
