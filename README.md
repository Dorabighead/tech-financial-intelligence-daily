# tech-financial-intelligence-daily

> 每日技术与金融情报日报 —— 一个由 AI 自动采集、撰写并持续更新的个人情报知识库。

## 📌 这个仓库是干嘛的？

本仓库是 **WorkBuddy 定时任务「dailyArc 自动同步」** 的产物沉淀，每天上午 11:00 由 AI 自动执行一轮完整的情报采集与分析流程，生成一份 Markdown 格式的日报，并自动提交推送到本仓库。

它解决一个核心问题：**信息过载时代，如何用有限的时间掌握真正值得关注的技术与金融动态**。

每份日报都遵循统一原则：

- **新颖**：优先采集过去 24 小时的信息，必要时扩展至最近 7 天（注明发生日期）
- **准确**：所有重要信息附原始来源链接，不允许编造项目、时间、数据
- **有深度**：不只总结"发生了什么"，还分析"为什么值得关注"

## 📂 目录结构

```
tech-financial-intelligence-daily/
├── README.md                          # 本文件：仓库说明
└── reports/                           # 每日日报归档
    └── YYYY-MM-DD-技术与金融情报日报.md # 以日期命名的日报
```

## 🔄 运作机制

```
每天 11:00 定时触发（WorkBuddy 自动化任务）
        │
        ▼
AI 从多个信息源采集过去 24h 的重要情报
（GitHub Trending / Releases / 官方博客 / 科技媒体 / 财经资讯等）
        │
        ▼
交叉验证信息真实性，过滤营销噪音，筛选高价值内容
        │
        ▼
撰写结构化 Markdown 日报
        │
        ▼
保存到 reports/YYYY-MM-DD-技术与金融情报日报.md
        │
        ▼
git commit + push，自动同步到 GitHub
```

## 📖 如何使用

- **每日速览**：直接打开当天日期的日报，了解昨天到今天发生了什么
- **主题追踪**：通过 GitHub 的文件搜索，按关键词检索历史日报中的某项技术 / 公司 / 项目
- **回溯复盘**：按日期浏览历史日报，观察某个技术或市场趋势的演进过程
